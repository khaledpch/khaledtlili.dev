## Start with business rules

A folder structure is not a domain model. Begin with business language, invariants and boundaries.

## An aggregate in practice

An order controls which changes are allowed after confirmation. The application service coordinates the operation while the domain owns the rule.

```php
public function confirm(): void
{
    if ($this->items->isEmpty()) {
        throw new DomainException('Order cannot be empty.');
    }
    $this->status = OrderStatus::Confirmed;
}
```
